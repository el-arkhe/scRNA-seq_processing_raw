# Procesamiento de datos scRNA-seq: cómputo en la nube con Cell Ranger y agentes de IA

Estimadas y estimados participantes:

¡Bienvenidos al curso intensivo “Procesamiento de datos scRNA-seq: cómputo en la nube con Cell Ranger y agentes de IA”!

Antes de la primera sesión, por favor revisen el documento adjunto y completen los prerrequisitos indicados, incluyendo la creación y configuración de sus cuentas de 10x Genomics Cloud y Claude Desktop.

## Objetivo del curso

Este curso tiene como finalidad introducir la tecnología single-cell, y poner en práctica el procesamiento de datos datos (FASTQ) de expresión scRNA-seq con el apoyo de agentes de IA. Veremos:

- datos scRNA-seq, tipos, químicas y pipelines de 10x Genomics
- identificación de datasets de interés
- preparación de datos y calidad de librerías
- Cell Ranger para alineación, cuantificación y generación de resultados preliminares
- ejecución manual de análisis en la nube mediante 10x Genomics Cloud
- integración de agentes de IA para apoyo analítico, automatización y resolución de tareas dentro de flujo de Cell Ranger
- función del CLI de Cell Ranger
- exploración de resultados mediante el reporte de Cell Ranger
- introducción a herramientas de visualización

## Prerrequisitos

Antes de comenzar, es necesario completar los siguientes pasos:

1. Revisar el material adjunto del curso.
2. Crear una cuenta en 10x Genomics Cloud.
3. Configurar correctamente la cuenta de 10x Genomics Cloud para acceder a los recursos de cómputo y almacenamiento del curso.
4. Instalar y configurar Claude Desktop.
5. Verificar acceso a los datasets oficiales de 10x Genomics que utilizaremos durante el taller.
6. Confirmar que cuenta con un navegador actualizado y acceso estable a internet.

## Cuentas requeridas

### 10x Genomics Cloud

Debe crear su cuenta en 10x Genomics Cloud y asegurarse de que:

- pueda iniciar sesión correctamente
- tenga acceso a la interfaz de análisis en la nube
- pueda cargar o seleccionar los datasets del curso
- esté listo para ejecutar trabajos con Cell Ranger

### Claude Desktop

Debe instalar y configurar Claude Desktop de acuerdo con las instrucciones del curso. Esto permitirá participar en actividades prácticas con agentes de IA y explorar flujos de asistencia analítica durante el curso.

## Datasets del curso

Durante el curso trabajaremos con los siguientes datasets oficiales de 10x Genomics:

- 5k Human PBMCs – Donor 3
- 5k Human PBMCs – Donor 4

Estos datasets serán utilizados para ilustrar el procesamiento, la calidad, la cuantificación y el análisis de datos scRNA-seq en entornos de cómputo en la nube.

## Recomendaciones generales

- Llegar con la cuenta de 10x Genomics Cloud lista y funcional.
- Confirmar que Claude Desktop esté instalado y accesible.
- Tener al menos un navegador web actualizado y acceso a la terminal del sistema operativo si se requiere.
